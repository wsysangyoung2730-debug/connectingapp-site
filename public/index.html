01

어디에 적용되나요?

이 방침은 우상영이 운영하는 날담 iOS 앱과 이 개인정보처리방침 안내 웹사이트에 적용됩니다. 날담은 하루의 경험을 기록하고, 관심사가 비슷한 사람을 발견하고, 서로 수락한 1:1 대화를 나누는 서비스입니다.

날담은 서비스에 필요한 정보를 아래 목적과 범위 안에서 처리합니다. 기록 기능과 로그인 후 사용하는 발견·대화 기능은 정보를 보관하는 위치가 다릅니다.

03

어떤 목적으로 사용하나요?

  • 하루 기록답변 저장, 지난 기록 확인, 작성 중인 내용 복원
  • 계정과 발견이용자 인증, 공개 프로필 표시, 공통 관심사에 따른 추천
  • 대화 연결대화 요청 및 수락, 메시지 전송·조회, 읽음 상태와 차단 기능
  • 서비스 보호와 문의접근 권한 확인, 부정 이용 방지, 이용자 문의와 권리 요청 처리

개인 일기를 광고 타기팅에 사용하지 않습니다. 현재 앱에는 광고, Google Analytics, Crashlytics SDK를 사용하지 않습니다.

04

다른 사람에게 무엇이 보이나요?

공개 프로필의 닉네임과 관심사는 로그인한 다른 이용자에게 표시됩니다. 메시지는 해당 1:1 대화의 참여자에게 표시되며, 개인 일기와 기기 안의 사진은 공개 프로필이나 대화에 자동으로 공유되지 않습니다.

이용자가 선택한 공개·전송 범위와 아래 서비스 운영 위탁을 제외하고, 개인정보를 판매하거나 광고 목적으로 제3자에게 제공하지 않습니다. 법령에 따른 의무가 있는 경우에는 해당 법령이 허용하는 범위에서 처리할 수 있습니다.

05

어디에서 처리되나요?

계정 인증과 대화 저장을 위해 Google LLC의 Firebase를 이용합니다. Apple 로그인 과정의 Apple 계정 정보 처리는 Apple의 개인정보 보호정책이 함께 적용됩니다.

인증 처리 · 미국

Firebase Authentication

로그인할 때 계정 식별자와 인증 정보 등이 암호화된 네트워크를 통해 전달됩니다. Google은 Authentication 데이터를 미국에서 처리한다고 안내합니다. 인증 제공, 계정 유지와 부정 이용 방지에 사용됩니다.

데이터베이스 · 대한민국 서울

Cloud Firestore

공개 프로필, 대화와 메시지, 읽음·차단 상태를 저장합니다. 현재 데이터베이스 위치는 서울(asia-northeast3)입니다. 서비스 운영 과정의 기술·지원 정보 처리에는 Google의 처리 약관 및 하위 처리업체 정책이 적용됩니다.

로그인 및 대화 사용 중 위 정보가 전송됩니다. 국외 인증 처리를 원하지 않는 경우 Apple 로그인을 이용하지 않을 수 있으며, 이 경우 로그인이 필요한 발견·대화 기능은 이용할 수 없습니다. 이미 저장된 정보의 삭제나 처리 정지는 아래 문의처로 요청할 수 있습니다.

보관 기간은 아래 기준과 Firebase의 삭제 절차를 따릅니다. Google은 Authentication의 IP 주소를 몇 주간 보관하며, 계정 삭제가 시작된 후 인증 정보를 활성 시스템과 백업에서 제거하는 데 최대 180일이 걸릴 수 있다고 안내합니다.

Firebase 개인정보 안내 ↗Google 데이터 처리 약관 ↗Apple 개인정보 보호 ↗
06

언제까지 보관하고, 어떻게 삭제하나요?

기기에 저장한 정보

기기 내 기록과 설정은 이용자가 해당 데이터를 삭제하거나 앱 데이터를 제거할 때까지 보관됩니다. 기기 백업이 있다면 백업에 사본이 남을 수 있습니다.

서버에 저장한 정보

계정과 공개 프로필, 전송된 대화 정보는 서비스 제공을 위해 보관됩니다. 계정 또는 데이터 삭제 요청을 받으면 본인 확인 후 처리 범위를 확인하고, 불필요해진 정보를 삭제합니다. 법령상 보존이 필요한 정보가 있다면 해당 근거와 기간을 안내하고 다른 용도로 사용하지 않습니다.

전자적 정보는 서버의 삭제 기능 등을 이용해 복구할 수 없도록 처리합니다. 백업과 인증 서비스에 남은 정보는 해당 서비스의 삭제 주기에 따라 제거될 수 있습니다.

08

정보를 보호하기 위한 조치

인증된 이용자와 대화 참여자에 따라 서버 데이터의 접근 권한을 제한합니다. Firebase로 전송되는 데이터는 HTTPS로 보호되며, Firebase Authentication과 Cloud Firestore는 저장 데이터 암호화를 제공합니다.

앱은 운영체제의 보호 기능을 사용해 기기 데이터를 보관합니다. 운영에 필요한 관리자 접근과 서비스 제공업체의 처리가 있을 수 있으며, 현재 대화 기능은 종단 간 암호화 기능을 제공하지 않습니다.

09

이 웹사이트와 쿠키

이 안내 페이지는 로그인이나 정보 입력 없이 읽을 수 있습니다. 광고·분석용 쿠키와 방문자 추적 도구를 설치하지 않으며, 기기의 기본 글꼴과 사이트에 포함된 애니메이션만 사용합니다.

웹페이지 제공 및 보안을 위해 호스팅 서비스에서 IP 주소, 요청 시각, 브라우저 정보 같은 접속 정보를 처리할 수 있습니다. 문의하기를 누르면 이용자가 사용하는 이메일 앱이나 서비스가 열리며, 실제 메일을 보낼 때 해당 서비스의 개인정보 정책이 적용됩니다.
